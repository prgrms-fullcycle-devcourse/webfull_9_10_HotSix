# Keyboard Warrior Battle Royale Requirements

## 1. Product Summary

- 서비스명: `키보드 워리어 배틀로얄`
- 플랫폼: 웹 브라우저 기반 실시간 타이핑 배틀
- 핵심 경험: 사용자는 접속 즉시 익명 계정을 발급받고, 대기방 입장 후 자동 시작되는 게임에 참가하거나 관전한다.

## 2. Core User Flow

1. 사용자가 웹 페이지 첫 방문 시 익명 사용자 계정이 자동 생성된다.
2. 사용자는 `시작하기` 버튼을 눌러 현재 라운드 상태에 따라 대기 모드, 게임 진행 모드, 관전 모드 중 하나로 입장한다.
3. 게임이 대기 중이면 참가자로 등록되고, 진행 중이거나 이미 탈락한 경우 관전 모드로 전환된다.
4. 정해진 대기 시간이 끝나면 서버가 자동으로 게임을 시작한다.
5. 참가자는 제시된 장문을 정확하게 입력해야 하며, 오타가 발생하는 즉시 탈락한다.
6. 한 명이 먼저 전체 문장을 완성하거나 생존자가 한 명만 남으면 게임이 즉시 종료된다.
7. 종료 후 랭킹, 통계, 다음 게임 시작 시간이 갱신된다.

## 3. Functional Requirements

### 3.1 Anonymous User

- 첫 접속 시 서버는 랜덤 닉네임, 랜덤 아바타, `UUID`를 생성한다.
- 서버는 액세스 토큰과 리프레시 토큰을 발급한다.
- 재접속 시 기존 `UUID` 또는 리프레시 토큰으로 동일 사용자를 식별한다.
- 닉네임은 중복될 수 없으며, 서버가 자동으로 중복을 회피한다.

### 3.2 Waiting Mode

- 사용자는 현재 대기 상태의 게임 정보와 다음 시작 예정 시간을 확인할 수 있어야 한다.
- 최소 시작 인원은 기본값 `1명`으로 둔다.
- 화면에는 현재 대기 인원 수, 내 닉네임, 게임 요약 규칙이 노출되어야 한다.
- 대기 시간이 종료되면 서버가 자동으로 게임을 시작한다.

### 3.3 Game Play

- 화면 왼쪽에는 참가자 목록과 현재 순위가 실시간으로 표시된다.
- 화면 오른쪽에는 제시 문장과 입력 필드가 표시된다.
- 사용자가 입력한 문자는 서버 기준 정답 문자열과 즉시 비교된다.
- 오타가 하나라도 발생하면 즉시 탈락 처리된다.
- 탈락한 사용자는 즉시 관전 모드로 전환된다.
- 우승 조건:
  - 한 사용자가 전체 문장을 먼저 정확히 완료한 경우
  - 다른 참가자가 모두 탈락하여 생존자가 한 명만 남은 경우
- 생존 기록 조건:
  - 최소 1글자 이상 정상 입력했을 것
  - 오타 없이 완주했거나 우승했을 것

### 3.4 Spectator Mode

- 게임 도중 입장한 사용자는 관전자로 입장한다.
- 관전자는 참가자 진행률, 참가자 수, 탈락자 수, 관전자 목록을 확인할 수 있어야 한다.
- 관전자는 게임 입력 이벤트를 전송할 수 없어야 한다.

### 3.5 Dashboard

- 사용자는 자신의 누적 통계를 조회할 수 있어야 한다.
- 노출 지표:
  - 닉네임
  - 평균 순위
  - 최근 순위
  - 플레이 횟수
  - 가입일
  - 최고 순위

## 4. Non-Functional Requirements

- 실시간 상태 동기화는 WebSocket 기반으로 처리한다.
- 주요 상태 조회와 인증, 대시보드는 REST API로 제공한다.
- 브라우저 강제 종료 또는 일정 시간 무응답 사용자는 실격 처리할 수 있어야 한다.
- 여러 탭 동시 접속 제한은 우선 DB 변경 없이 소켓 세션 또는 Redis 상태 기준으로 제어한다.
- 모든 시간은 서버 기준으로 판정한다.

## 5. Game Rules and Assumptions

- 진행 중인 게임에 입장하면 무조건 관전자로 처리한다.
- 이미 탈락한 사용자는 같은 라운드에 재참가할 수 없다.
- 입력 무응답 제한 시간은 운영 정책값으로 관리한다. 기본 예시는 `10초`.
- 동일 사용자의 멀티 탭 접속 방지는 소켓 연결 시 기존 활성 세션을 종료하거나 새 연결을 거절하는 방식으로 구현한다.

## 6. API Design Scope

- 이번 OpenAPI 문서는 다음 범위를 포함한다.
  - 익명 사용자 생성 및 재발급
  - 내 정보 조회
  - 대기/게임/관전 상태 조회
  - 대시보드 통계 조회
  - 현재 라운드 참가/관전 입장
  - WebSocket 이벤트 규약 설명
