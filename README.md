# Keyboard Warrior Battle Royale

핫식스 팀의 `키보드 워리어 배틀로얄` 프로젝트 레포지토리입니다.

## 프로젝트 소개

타이핑 실력으로 배틀로얄을 펼치는 하드코어 웹게임 서비스 

## 기술 스택

### 공통

- Package Manager: `pnpm`
- Language: `TypeScript`

### Frontend

- React
- Tailwind CSS
- React Query
- Zustand
- Vite

### Backend

- NestJS
- Socket.IO
- Supabase
- Redis
